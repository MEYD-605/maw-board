Oracle Board — collaborative terminal + workboard

Oracle Board is the MEYD collaborative terminal and workboard — multiplayer canvas, files, sysstat, password gate — run via maw board.

Real-time collaboration, remote cursors, and end-to-end encryption on a lightweight Rust server. Derived from open-source sshx (see NOTICE / LICENSE).

Install the workboard plugin, then open with maw board. Use it for fleet ops, teaching, debugging, and house agent terminals.

Collaborative

Invite people by sharing a secure, unique browser link.

End-to-end encrypted

Send data securely; the server never sees what you're typing.

Cross-platform

Use the command-line tool on macOS, Linux, and Windows.

Infinite canvas

Move and resize multiple terminals at once, in any arrangement.

Live presence

See other people's names and cursors within the app.

Ultra-fast mesh networking

Connect from anywhere to the nearest distributed peer in a global network.

Installation

macOS / Linux

Install the maw plugin, then the prebuilt workboard runtime:

maw plugin install MEYD-605/maw-workboard

Prebuilt bundles (Linux / macOS) from MEYD releases:

maw board install --prebuilt ./workboard-prebuilt-<os>.tar.gz

Release assets: workboard-v0.1.0

maw board serve

Then open http://127.0.0.1:3457/go

Build from source

Clone MEYD-605/maw-board, install Rust + protoc + Bun, then build and install via the workboard plugin.

git clone https://github.com/MEYD-605/maw-board && maw board install --source ./maw-board

Friend house

Board + oracle-menu pack notes live in maw-workboard templates (friend-house pack). Product name to search: Oracle Board — not bare “sshx”.
